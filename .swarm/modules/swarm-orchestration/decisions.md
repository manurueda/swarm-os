## 2026-08-15 — The module analyst fills whatever room it is given, so telling it to write less does not make it write less. MODULE_ANALYSIS_SCHEMA in packages/core/src/swarm/analyst.ts is a static constant whose maxItems (entryPoints 8, landmarks 12, invariants 10, gotchas 10, publicInterface 12) is the only thing that actually bounds how big a module's memory.md gets - roughly forty bullets, which measured at 2263 tokens against a 2000 budget on a real repository. Keep MODULE_ANALYSIS_SCHEMA exported for the unsplit case so existing callers and index.ts keep working. Add a test that a split module's schema is strictly tighter than an unsplit one, and that the unsplit case is unchanged. npm test must pass.

Change no behaviour. npm test must pass.
